# CP08 — project component mapping

Explicit options.components points to a confined project ES module. It exports components({element}) or a default function mapping; element is a renderer-neutral semantic constructor supplied internally by the helper. Synchronous adapters receive evaluated props/children; async adapters are rejected. Unknown names and thrown adapter errors fail, not disappear. Mapping root is reported as a dependency; transitive closure belongs to CP10.

Acceptance: seventeen tests passed: Aside semantic output, nested JSX, fragments, boolean/string/expression props, escaping, adapter exceptions, async refusal and unknown component failures. Factory does not require project authors to import a browser React runtime.
