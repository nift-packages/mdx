# CP11 — bounded practical Markdown pipeline

Defaults: CommonMark + pinned GFM + stable mdx- heading IDs. No default raw-HTML plugin, smart punctuation or highlighter ecosystem. Explicit local remark/rehype plugin hooks are tracked.

Acceptance: focused tests passed tables/literal autolinks/strike/task lists/footnotes, duplicate prefixed headings, no unsolicited smart punctuation, JSX HTML and inert fenced MDX examples. Existing tests cover nested lists/code/language classes/links/images/escaping. HTML-comment MDX syntax fails explicitly.
