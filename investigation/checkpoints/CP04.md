# CP04 — basic static rendering

Pinned MDX compile + run + build-time React renderToStaticMarkup now powers each request in one worker process. Compiler/evaluate/render times and structured stage-specific failures are returned. Imports/re-exports are explicitly refused until module-resolution checkpoint, rather than executed by native Node implicitly. Public response remains HTML, not React objects.

Acceptance: nine tests pass, including heading, paragraph, emphasis, links, nested lists, inline/fenced code, image/escaping and no injected React/JSX/hydration assets. Mixed-success batches retain request identity and report unknown components/malformed MDX.
