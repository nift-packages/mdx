# CP12 — package scanner optimization

No Nift core edits. Native byte-indexed string searches/splits replace hot byte-at/length calls and per-byte plain Markdown/JSX text scanning. CR/LF line starts, fence boundaries, escaped delimiters, paragraph-boundary import/export rules and UTF-8 positions retain original semantics. Dense syntax still costs substantial interpreter time; do not generalize prose improvements to all MDX.
