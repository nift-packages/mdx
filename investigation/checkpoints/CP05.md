# CP05 — additive installed facade

Public facade now adds prepare(documents) and html(document); parse/input signatures and exact result shape are unchanged. prepare takes parsed documents, reads explicit project policy/config, transports one batch via unique request/response filenames and populates per-document prepared records. html(input document) is read-only and refuses missing/stale prepared state; html(parse source) supports intentional one-off invocation. A configured pre-build script prepares all required documents once. Scalar file calls never silently spawn per-target renderers.

Process authority is probed with node --version before any request-file write so fatal --no-process rejection leaves no request behind. This adds one small Node launch per batch, not per target; measure it in whole-build benchmarks. Transport uses file values/structured argv with unique secure random names. Full pre-build incremental/invalidation integration remains CP10/15/21. No browser runtime.
