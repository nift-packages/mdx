# CP03 — versioned batch transport

One Node invocation accepts version1 JSON request file with ordered unique document IDs, source/path/dependencies and explicit options. Worker memory cap512MiB; configurable deadline1..600000ms (default120000); request16MiB, response64MiB, document256KiB, aggregate8MiB,1000 documents. CLI paths are confined to project including request symlinks. Response is atomic and temp files are cleaned. Errors include stage/code/message/path/line/column; stdout/stderr are separate from the response. No shell interpolates source. Compiler remains an explicit not_implemented response until CP04.

Acceptance: seven protocol tests passed: normal ID transport, duplicate IDs, policy refusal, malformed JSON, timeout, Unicode/quotes/newlines in space/Unicode paths, oversized source refusal. Existing Nift run uses structured argv. Missing helper/process and installed facade integration are covered when facade is introduced.
